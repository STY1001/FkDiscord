# 🧹 FkDiscord

A BetterDiscord plugin to remove all the annoying garbage from Discord that forces on you (Nitro promotions, Quests, Shop, Boost banners, profile decorations, server tags, and more)

Currently only available for **BetterDiscord**. Support for other clients may come in the future.

## ✨ Features

FkDiscord currently remove all these craps:

**Private Messages**
- Nitro button in the DM list
- Quests button in the DM list
- Shop button in the DM list
- Friends' activity status ("now playing")

**Global UI**
- GIF button in the chat input
- Super Reactions toggle in the emoji picker

**Servers**
- Server Boost banner in the channel list
- Server Boost channel button
- Member activity status in the member list

**Settings**
- Nitro-related tabs in the Discord settings modal

**User Profiles**
- Nameplates
- Avatar decorations
- Server tags (in chat, member lists, and profiles)
- Custom profile themes (restores your own theme instead)
- Profile effects
- Profile banners
- Display name styles (custom fonts/colors on usernames)
- Shop button on your own profile
- Style side panel on your own profile
- Nitro/Quest badges, with the option to keep specific ones (HypeSquad, "Originally Known As")

## ⬇️ Installation

1. Make sure [BetterDiscord](https://betterdiscord.app/) is installed.
2. Download `FkDiscord.plugin.js` from the [latest release](https://github.com/STY1001/FkDiscord/releases) or directly from this repo.
3. Move the file into your BetterDiscord plugins folder:
   - Open Discord settings → BetterDiscord → Plugins → click the folder icon, **or**
   - Navigate manually to `%AppData%\BetterDiscord\plugins` (Windows).
4. Enable **FkDiscord** in the Plugins tab.

## 🔧 Configuration

Every feature can be toggled individually from the plugin's settings panel (Settings → Plugins → FkDiscord → gear icon). By default, all removal is enbaled.
The plugin also checks for updates on startup and can update itself with a single click when a new version is available.
